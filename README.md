# ⚔️ Slay the Spire Deck Builder

A web-based deck builder for planning and theorycrafting Slay the Spire decks.

## Features

- **All 4 Characters**: Build decks for Ironclad, Silent, Defect, and Watcher
- **Comprehensive Card Database**: Includes all cards with accurate descriptions, costs, and rarities
- **Smart Filtering**: Filter by character, rarity, type, or search by name
- **Deck Statistics**: View detailed stats including:
  - Total card count
  - Average energy cost
  - Card type distribution (Attack/Skill/Power)
  - Rarity breakdown
- **Import/Export**: Save and share your deck builds with JSON export/import
- **Beautiful UI**: Character-themed color scheme with responsive design

## How to Use

1. Open `index.html` in your web browser
2. Select your character from the dropdown
3. Click on cards to add them to your deck
4. Use filters to find specific cards
5. View your deck statistics in real-time
6. Export your deck to share or save for later

## Technologies

- Pure HTML, CSS, and JavaScript
- No dependencies or build tools required
- Works offline

## Card Data

The deck builder includes:
- **Ironclad**: 80+ cards including Demon Form, Barricade, and Corruption
- **Silent**: 80+ cards including Wraith Form, Burst, and A Thousand Cuts
- **Defect**: 70+ cards including Echo Form, Creative AI, and Electrodynamics
- **Watcher**: 70+ cards including Deva Form, Master Reality, and Vault
